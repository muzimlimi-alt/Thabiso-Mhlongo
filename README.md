# Thabiso Mhlongo Official Website

A premium, bespoke digital platform for South Africa's freshest comedy voice. Built with an "Obsidian & Gold" editorial-luxe aesthetic, featuring a full-service booking engine, financial management, and real-time administrative transparency.

## 🚀 Quick Start

### 1. Installation
```bash
npm install
```

### 2. Configuration
Copy `.env.example` to `.env` and fill in your credentials:
```bash
cp .env.example .env
```

### 3. Run Development Server
```bash
npm start
```

## 🛠 Tech Stack
- **Frontend**: Vanilla JS (ES6+), HTML5, CSS3 (Modular Architecture), GSAP (Animations), ScrollReveal.
- **Backend**: Node.js (Express), SQLite3.
- **Security**: Helmet, bCrypt, XSS-Clean, Express-Rate-Limit.
- **Integrations**: Google Calendar API, Nodemailer, PDFKit (Invoicing).

## 📊 Management
Access the admin dashboard at `/admin.html`.
*Use the Admin Guide for detailed operational instructions.*

## 💾 Backups
Automated snapshots are maintained in the `/backups` folder.
To manually trigger a backup:
```bash
npm run backup
```
